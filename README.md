# GeoStream

Микросервис для приёма, обработки и хранения GPS-точек курьеров в реальном времени.

**Смысл:** сервис принимает поток GPS-координат от курьеров, фильтрует нулевые координаты, группирует точки в батчи и сохраняет их в PostgreSQL. Через HTTP API можно получить последнюю известную точку любого курьера.

Проект демонстрирует **production-like** архитектуру на Scala 3 с использованием функциональных эффектов, обработки FS2 и  SQL.

---

## Возможности

- **Потоковая обработка (FS2)** — бесконечный поток GPS-точек, фильтрация, группировка через `groupWithin` (batching по размеру или времени).
- **Типобезопасный SQL** — запросы проверяются на этапе компиляции, `UPSERT` для обновления последней точки курьера.
- **HTTP API (http4s)** — `GET /couriers/{id}/last-point` возвращает JSON с координатами и timestamp.
- **Управление ресурсами (Cats Effect `Resource`)** — соединение с БД корректно закрывается при остановке приложения.
- **Dependency Inversion** — интерфейс `GpsRepository` имеет две реализации: in-memory (`Ref`) для тестов и PostgreSQL для production.
- **Docker Compose** — PostgreSQL поднимается одной командой, схема создаётся автоматически через `init.sql`.
- **Persistence** — данные переживают перезапуск приложения.
- **Обработка ошибок** — логирование ошибок БД, HTTP 404 для несуществующих курьеров.
